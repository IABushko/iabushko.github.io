How does this work: Black paint balls are like X-ray beams. When they hit the tree, some get blocked and some pass through. This is how X-ray images are made: bones block most beams and appear white, soft tissues block some and appear gray, and air lets beams pass through, so it looks black.
Paint Ball Simulation X-ray
Blocked paint balls → white canvas Blocked X-rays → white (e.g. bone)
Paint balls pass through → black canvas X-rays pass through → black (e.g. air)
Simple Rule to Remember:
⏺ More balls = clearer image
⏺ More power = can pass through more easily
⏺ More distance = spreads out, covers more
